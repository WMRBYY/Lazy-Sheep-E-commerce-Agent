# 公开范围

此版本保留未被明确排除的现有功能，包括电商图片与普通视频生成、完整画布、用户管理、积分及通用支付代码。

## 完全不包含

- 灵犀中枢、电商视频复刻、剧本创作的前端实现、后端流程、提示词、数据模型、迁移、预置数据及业务数据。
- 电商视频 Agent 的实现、知识库、后台配置及后台数据。
- 现有生产数据库、账号、商户资料、中转配置、密钥、客户资料、上传文件、日志、未经脱敏的截图、备份与历史提交。

视频复刻和剧本创作的侧栏入口只保留禁用图标。灵犀中枢无公开入口。

## 移除的后台管理模块

系统更新、模型响应拦截、第三方参数配置、方舟素材库、站点及外观、AI 虚拟助手、电商视频 Agent、官方素材库、技能分类、技能管理、MCP 管理、插件管理、绘图工具工作台、工具及 Agent 记忆管理。

上述管理页面与管理接口不开放。保留功能依赖的通用内部组件可以继续存在；例如通用支付适配器不等于插件管理页面，普通视频生成不包含电商视频 Agent 的私有流程。

## 空配置与新数据

部署时创建新数据库；不提供原站数据。保留功能可以存储部署者自己的新数据。
公共开源依赖、附带许可证的公共行业分类与通用字体，不属于原站业务数据库。
原站预置技能、素材及私有知识内容不随本仓库发布。
README 使用经维护者选定的界面截图作为文档插图。
